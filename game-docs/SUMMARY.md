## ภาพรวมความก้าวหน้า (ตามการคำนวณ)
- ฆ่าก็อบลินให้เลเวลอัป: ~6 ตัวที่ Lv.5 → ~12 ที่ Lv.10 → ~26 ที่ Lv.30 → ~55 ที่ Lv.99
- ตีบวกครบทั้งหมด (ดาบ +10 + สกิลทั้ง 3 ถึง Lv.10) ใช้ทองรวมประมาณ 90,000G (ดาบ ~26,600 + สกิล ~64,600) และวัตถุดิบจากมอนสเตอร์หลายชนิด
- ทองต่อก็อบลิน: ~25G ที่ Lv.10 → ~51G ที่ Lv.30 → ~90G ที่ Lv.60
