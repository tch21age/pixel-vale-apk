## อุปกรณ์ตามระดับดาบ (P.wl 0..5)
- สีใบดาบ/อัญมณีคทา = `BLADE[wl]` (เหมือนเดิม)
- ชาย: ผ้าคาดหัวแดง → หมวกหนัง → หมวกเหล็ก (+2) → + ขนนก (+3) → + โล่ (+4) → ทองคำ (+5)
- หญิง: โบว์ชมพู → หมวกแม่มดเล็ก → หมวกพ่อมดสูง (+2) → + อัญมณี (+3) → + ดาวที่ปลายหมวก (+4) → ปีกหมวกทอง (+5)
- ตีบวกดาบ: ไม่ต้องทำอะไร — คีย์ cache คือ `g+wl` จึงสร้างเฟรมใหม่เองตอนใช้

## v8: แก้อาการกระตุกตอนฟันและใช้สกิล
**สาเหตุที่พบ** (วัดด้วย Playwright/Chromium จำลอง จับเวลา `render()` ต่อเฟรม)
1. เฟรมฮีโร่ท่าฟัน/ร่าย (≈28 เฟรม/ลุค) ถูก bake ครั้งแรกกลางการเล่น ~9–10 ms/เฟรมที่เครื่องทดสอบ (`getImageData` ทุกเลเยอร์) → กระตุกที่ฟัน/สกิลครั้งแรกของทุกทิศ
2. เฟรมมอนสเตอร์ bake ตอนเจอครั้งแรก (ตัวแรกที่วัดได้ ~144 ms) และภาพขาววาบตอนโดนตีสร้างครั้งแรกตอนโดนจริง
3. เอฟเฟกต์ฟัน/ลูกไฟ/ระเบิด/ฟันหมุน ฯลฯ bake ตอนเริ่มวาดครั้งแรก
4. แคนวาสของ `GFX.layer` เป็น `willReadFrequently` (CPU-backed) แต่ถูกใช้ตรงๆ เป็นสไปรต์ → drawImage ต้องอัปโหลดซ้ำ
5. `pixText` ใช้ `strokeText` ทุกเฟรมสำหรับชื่อ/ตัวเลขดาเมจ

3. **bake เฟรมตอนเล่น**: v8 ใช้คิวตอนว่างในเกม ซึ่งบนมือถือเฟรมแน่นจึงทำงานช้า/ล้นเฟรม → ย้ายไป bake **ตั้งแต่หน้าเริ่มเกม** (ฮีโร่ชาย/หญิงที่ดาบ +0, มอนสเตอร์, เอฟเฟกต์, ตัวอักษร) ด้วยงบ 14 ms/รอบ · หลังกดเริ่มเกม/โหลดเซฟมีช่วง "โหลด" 2.5 วินาทีที่ bake ลุคปัจจุบัน (ดาบ +n จากเซฟ) ด้วยงบเต็ม · ระหว่างเล่นงบเหลือ 2.5 ms/รอบ และเริ่มงานเฉพาะเมื่อเวลาเหลือพอ (ประมาณจาก EMA ของงานก่อนหน้า) · เปิดร้าน/หยุดเกมใช้งบเต็ม
